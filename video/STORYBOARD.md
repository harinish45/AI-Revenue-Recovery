# RecoverAI — 4:30 Recruiter Demo Storyboard

**Audience:** Razorpay buildathon judges and engineering recruiters  
**Format:** 16:9, exactly 270 seconds, English narration with captions  
**Visual direction:** a bright, high-contrast product frame built from RecoverAI's navy, indigo, mint, amber, and coral system. Avoid an all-black canvas. Use the real dashboard as the hero surface, with animated spotlight rings, cursor trails, metric callouts, workflow arrows, and a small bottom progress rail.

## Creative concept

**Revenue recovery as a control room:** every scene moves one signal through a visible chain—detect, diagnose, decide, act, measure, prove. The dashboard stays recognizable while overlays make the agent's reasoning legible to a recruiter.

## Scene map

| Time | Scene | Visual beats | Voice intent |
|---|---|---|---|
| 0:00–0:20 | The leak | Hook card; dashboard resolves into view; Test Mode badge and safety boundary are highlighted | Revenue loss is a sequence, not a single error |
| 0:20–0:55 | Detect | Seed Data; five metric cards count up; cases queue gets a mint scan line | RecoverAI turns risk signals into a measurable queue |
| 0:55–1:35 | Diagnose | Cases view; risk/status dropdowns; one inspection box; root-cause and recommended action callouts | The agent explains why a case is risky and what it will do |
| 1:35–2:20 | Decide and recover | Batch button; progress stages; smart-skip banner; recovered/cost/net/escalated economics panel | Policy gates choose the least-cost bounded intervention |
| 2:20–3:00 | Contain failure | Arm Failure Simulation; execute once; result modal changes to Result; human-review badge and terminal guard callout | Failure is contained and escalated rather than retried blindly |
| 3:00–3:55 | Human voice | Voice Agent; consent gate; English/Hinglish language switch; promise/dispute intent; audit confirmation | Multilingual recovery adds empathy without bypassing consent |
| 3:55–4:25 | Prove | Audit drawer; event timeline; seal verification; JSON/CSV export; workflow chain locks green | Every action is traceable and verifiable |
| 4:25–4:30 | Close | Metrics return; final statement and repository/live-demo lower third | A concise buildathon close |

## Visual treatment

- Base: deep blue-black `#07111f`, indigo panels, soft radial navy glow, visible grid texture.
- Focal accents: mint for recovered/safe, amber for risk, coral for escalation, electric blue for active focus.
- Typography: Montserrat for display/UI and Space Mono for IDs, audit hashes, timestamps, and API labels.
- Foreground details: `RECOVERAI / TEST MODE`, scene index, live-style timestamp, thin data rails, metric delta chips, and a moving spotlight ring around each click.
- Never leave a scene as a blank dark frame: each scene has the app surface, one large callout, two data details, and an active workflow marker.
